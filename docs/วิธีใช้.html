Doodee future

เก็บผลงานจากเล่ม portfolio ไว้ในเครื่องครั้งเดียว แล้วกรอกลง TCASFolio ได้ทุกแฟ้ม ทุกมหาวิทยาลัย โดยไม่ต้องพิมพ์ซ้ำ

Chrome · ใช้กับ student.mytcas.com · ข้อมูลอยู่ในเครื่องเท่านั้น ไม่ส่งไปไหน
สิ่งเดียวที่ต้องจำ: TCASFolio ไม่บันทึกเอง สิ่งที่ extension กรอกให้จะหายถ้าปิดหน้าโดยไม่กด บันทึกแฟ้ม (ปุ่มสีน้ำเงินมุมขวาบนของเว็บ) — กดบ่อย ๆ ระหว่างทำ ไม่ใช่รอจนเสร็จ

ติดตั้ง

  1. เปิด chrome://extensionsเปิด Developer mode ที่มุมขวาบน
  2. กด Load unpackedเลือกโฟลเดอร์ TCASFolio Extension ที่มีไฟล์ manifest.json
  3. ปักหมุดไอคอนไว้ที่แถบเครื่องมือจะได้กดเปิดคลังได้ทันที

รองรับ Chrome / Chromium / Edge / Brave — ไม่รองรับ Firefox และ Safari

นำเข้าจากไฟล์ PDF (เร็วที่สุดถ้ามีเล่มอยู่แล้ว)

กดไอคอนส่วนขยาย → นำเข้าจากไฟล์ PDF → เลือกไฟล์เล่มพอร์ต ระบบจะอ่านหัวข้อ รายละเอียด และรูปในเล่มออกมาเป็น "ร่างผลงาน" ให้ตรวจก่อนบันทึก

  1. เลือกไฟล์ .pdfลากมาวางก็ได้ · ไฟล์อ่านในเครื่องเท่านั้น ไม่ถูกอัปโหลดไปไหน
  2. รอระบบอ่านบอกความคืบหน้าเป็นหน้า ๆ · เล่ม 10 หน้าใช้เวลาไม่ถึงนาที · ยกเลิกกลางคันได้
  3. ตรวจร่างติ๊กเลือกชิ้นที่จะเอา แก้หัวข้อ/หมวด/ระดับ/รายละเอียดได้ในที่ และคลิกรูปในหน้านั้นเพื่อเลือกแนบ
  4. กด บันทึกเข้าคลังเพิ่มเป็นชิ้นใหม่ทั้งหมด — ของเดิมในคลังไม่ถูกลบหรือทับ

ที่ต้องรู้ก่อนใช้

  • ไฟล์ที่ทำจาก Canva มักฝังข้อความไทยสองชุด ชุดหนึ่งวรรณยุกต์หาย ระบบซ่อมให้อัตโนมัติ แต่บางบรรทัดอาจยังเพี้ยน — ตรวจในหน้าตรวจก่อนบันทึก
  • รูปจะขึ้นเยอะกว่าที่ใช้จริง เพราะ Canva ซอยภาพเดียวเป็นหลายชิ้น เลือกเฉพาะใบที่ต้องการ — ใบที่ไม่ได้คลิกจะไม่ถูกบันทึก
  • หน้าปก/หน้ารูปล้วนจะถูกข้าม และบอกเหตุผลไว้ท้ายหน้า
  • ไฟล์ สแกน (ไม่มีตัวอักษรจริง) อ่านไม่ได้ ต้องส่งออกใหม่จาก Canva/Word

1 · ใส่ผลงานเข้าคลัง

ทำครั้งเดียวจากเล่ม portfolio เดิม กดไอคอน extension แล้วกรอกทีละชิ้น

ช่องใส่อะไร
ประเภทเลือก 1 ใน 5 — ตรงกับปุ่ม ＋ เพิ่ม… ของ TCASFolio เป๊ะ: รางวัล/เกียรติบัตร · โครงงาน/วิจัย · กิจกรรม · การอบรม · ผลงานสร้างสรรค์

มีเล่ม PDF อยู่แล้ว? ไม่ต้องพิมพ์ทีละช่อง — ใช้ นำเข้าจากไฟล์ PDF ให้ระบบอ่านออกมาให้ แล้วมาแก้เฉพาะที่ผิด

2 · แนบรูปเกียรติบัตรไว้กับผลงาน

ในฟอร์มของแต่ละผลงาน กด ＋ แนบรูป เลือกได้หลายไฟล์ (JPG/PNG ไม่เกิน 2 MB ต่อใบ) เห็น thumbnail ทันที กด × บนรูปเพื่อเอาออก แล้วกด บันทึกลงคลัง

รูปเก็บในเครื่องผูกกับผลงานชิ้นนั้น ใช้ซ้ำได้ทุกแฟ้ม ลบผลงานแล้วรูปถูกลบตาม การ์ดที่มีรูปจะขึ้นป้าย 🖼 พร้อมจำนวน

3 · กรอกลง TCASFolio

เปิด student.mytcas.com เข้าแฟ้มที่จะทำ จะเห็นปุ่มเล็ก ๆ ▸ กลางขอบขวาของจอ — นั่นคือคลังผลงาน (เริ่มที่ย่อไว้ จะได้ไม่บังปุ่มของเว็บ) กดเพื่อกาง

  1. ในแถบคลัง หาผลงานชิ้นนั้น กด ＋ ลงพอร์ตสร้างบล็อกให้ตรงหมวดที่ตั้งไว้ในคลัง แล้วคลิกเลือกบล็อกให้เอง — ไม่ต้องไปกด ＋ เพิ่มรางวัล ของเว็บเองอีก
  2. ดู "แผน" ที่ขึ้นมาบอกว่าอะไรจะลงช่องไหน — ยังไม่เขียนอะไรลงไป ถ้าเห็นแปลก ๆ กด ยกเลิก (บล็อกเปล่าจะค้างไว้ ลบเองที่ปุ่มถังขยะของเว็บ)
  3. กด ยืนยันเติมลงให้ครบ: หัวข้อ · ระดับ · ผลรางวัล · หน่วยงานที่จัด · ช่วงเวลา/วันที่ · รายละเอียด — ถ้าผิดกด ย้อนกลับ คืนทุกช่องพร้อมกัน
  4. ติ๊ก ค่าใช้จ่าย เอง แล้วกด บันทึกแฟ้มค่าใช้จ่ายไม่มีในคลังและเดาแทนไม่ได้ · บันทึกแฟ้มเป็นปุ่มของเว็บ extension จะไม่กดให้

บล็อกที่มีอยู่แล้ว (เช่นจะเติมซ้ำ หรือทำสำเนามาจากสาขาอื่น) ให้คลิกเลือกบล็อกนั้นแล้วกด เติมทั้งฟอร์ม แทน

อยากกรอกทีละช่องแทน: คลิกช่องในเว็บก่อน แล้วกดปุ่ม ชื่อ หน่วยงาน รายละเอียด ในการ์ด — ถ้าช่องมีข้อความอยู่แล้ว ปุ่มจะเปลี่ยนเป็น ทับของเดิม? ต้องกดซ้ำ

หรือแค่ คัดลอกรายละเอียด แล้ว Ctrl+V เอง — วิธีเดิมยังอยู่

4 · ส่งรูปลงบล็อก

หลังเติมข้อความลงบล็อกแล้ว (หัวข้อในเว็บต้องตรงกับชื่อผลงานในคลังเป๊ะ) กด แนบรูป (N) ในการ์ดเดียวกัน รูปจะทยอยขึ้นทีละใบ รอจนเสร็จ — ปุ่มจะบอกว่าแนบใบที่เท่าไหร่

รูปถอนไม่ได้จากฝั่ง extension — พอขึ้นแล้วอยู่บนเซิร์ฟเวอร์ของ TCAS ทันที ถ้าผิดบล็อกให้ใช้ปุ่ม "ลบรูป" ของเว็บเอง ระบบจึงบอกชื่อบล็อกเป้าหมายก่อนใบแรกขึ้น และถ้าหาบล็อกที่ชื่อตรงไม่เจอจะไม่เดา

เลย์เอาต์ตั้งให้เอง — ก่อนแนบ ระบบจะเลือกเลย์เอาต์ให้พอดีจำนวนรูป (1 ใบ = เต็มกว้าง 4:3, 5 ใบ = "5 รูป") ไม่ต้องไปกดดรอปดาวน์ของเว็บ

รูปใหญ่ถูกย่อให้อัตโนมัติ — ใบไหนเกิน 1.2 MB หรือด้านยาวเกิน 1800 px จะถูกย่อก่อนอัป (ในคลังยังเก็บไฟล์เต็มไว้เหมือนเดิม) วัดจริง: รูป 6000×4000 หนัก 29 MB เหลือ 536 KB

ทำไมต้องย่อ — TCASFolio ส่งทั้งแฟ้มพร้อมรูปเป็นก้อนเดียวตอนกด "บันทึกแฟ้ม" ถ้าก้อนใหญ่เกิน เซิร์ฟเวอร์จะตีกลับ (413) แต่หน้าเว็บจะขึ้นว่า "เชื่อมต่อเซิร์ฟเวอร์ไม่สำเร็จ กรุณาตรวจสอบอินเทอร์เน็ตและไฟล์ที่แนบ" ซึ่งชวนให้เข้าใจผิดว่าเน็ตมีปัญหา

สำรองข้อมูล

ส่งออก JSON ในป๊อปอัป ได้ไฟล์ doodee-future-YYYY-MM-DD.json — ทำหลังใส่ผลงานเสร็จทุกครั้ง เพราะคลังอยู่ใน Chrome profile ล้างเบราว์เซอร์/ถอน extension แล้วหาย

นำเข้า JSON รวมเข้าคลัง (ไม่ทับทั้งก้อน) แล้วบอกว่าเพิ่มกี่ชิ้น อัปเดตกี่ชิ้น

JSON ไม่มีรูป — ไฟล์ส่งออกเก็บแค่ข้อความ เก็บไฟล์รูปเกียรติบัตรต้นฉบับไว้ในโฟลเดอร์ต่างหากด้วย แล้วค่อยแนบใหม่หลังนำเข้า

ระวัง — อ่านก่อนใช้จริง

  • กด บันทึกแฟ้ม บ่อย ๆ — ทุกอย่างที่ extension ทำ เว็บยังไม่ได้บันทึกจนกว่าจะกดปุ่มนี้ ปิดแท็บ/รีเฟรชก่อน = หายหมด
  • เติมเฉพาะช่องว่าง — ช่องที่มีข้อความแล้วระบบข้าม (แผนจะบอกว่าข้ามกี่ช่อง) ไม่ทับเรียงความ ไม่ข้ามไปบล็อกอื่น
  • ชื่อผลงานในคลังต้องตรงกับหัวข้อในเว็บ ถ้าไปแก้หัวข้อในเว็บเอง ปุ่มแนบรูปจะหาบล็อกไม่เจอ — แก้ในคลังให้ตรง หรือแนบรูปก่อนแก้
  • ข้อมูลที่เว็บ Verify แล้ว (ช่อง readonly) ระบบไม่แตะ และไม่แตะรหัสผ่าน/ช่องอัปโหลดไฟล์อื่น
  • ไม่มีอะไรออกจากเครื่อง — ไม่มี network call ในโค้ดเลยสักบรรทัด (ตรวจได้ด้วย grep)

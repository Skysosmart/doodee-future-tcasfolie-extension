# นำเข้าพอร์ตจากไฟล์ PDF — ดีไซน์

วันที่ 2026-08-24 · สถานะ: รออนุมัติก่อนลงมือ

## โจทย์

เล่มพอร์ตของผู้ใช้ทำใน Canva แล้วส่งออกเป็น PDF — ไม่มีโครงสร้าง ไม่มี metadata
ทุกวันนี้กว่าจะเอาลงคลังของส่วนขยายได้ ต้องเปิด PDF อ่านเอง พิมพ์เข้าฟอร์มทีละชิ้น
แล้วไล่หารูปเกียรติบัตรจากโฟลเดอร์มาแนบเอง

**เป้าหมาย:** เลือกไฟล์ PDF หนึ่งไฟล์ → ส่วนขยายอ่านเอง → เสนอ "ร่างผลงาน" เป็นชิ้น ๆ
พร้อมรูปที่อยู่ในหน้านั้น → ผู้ใช้ตรวจ/แก้/ติ๊กเลือก → บันทึกเข้าคลัง

## ไม่ทำ (non-goals)

- **ไม่แตะระบบเดิม** — `content.js` `content.css` `storage.js` `model.js` `inject.js`
  ทำงานเหมือนเดิมทุกบรรทัด ระบบใหม่มีตัวย่อรูปของตัวเอง ไม่ไปรีแฟกเตอร์ของเดิมมาใช้ร่วม
- **ไม่ทำ OCR** — ไฟล์สแกน (ไม่มี text layer) จะบอกว่าอ่านไม่ได้ ไม่ใช่เดามั่ว
- **ไม่ต่อเน็ต** — pdf.js ฝังมาในส่วนขยาย ไฟล์ไม่ออกจากเครื่อง
- **ไม่บันทึกให้เอง** — ร่างจะเข้าคลังต่อเมื่อผู้ใช้กดบันทึก และไม่ลบ/ทับของเดิม

## หลักฐานที่ทำให้ทำได้จริง (วัด 2026-08-24)

ไฟล์ Canva ฝัง**ข้อความสองชุดซ้อนกัน** ชุดหนึ่งวรรณยุกต์/สระหาย อีกชุดถูกต้อง ปนกับเศษบรรทัด:

```
ผลงานนวัตกรรม PDlite ทีได้ผ่านการคัดเลือกของสํ      ← พิการ (มาร์ก 6 ตัว)
ผลงานนวั                                            ← เศษ
ที่ได้ผ่านการคัดเลือกของสำนักงานการวิจัยแห่งชาติ   ← ถูกต้อง (มาร์ก 12 ตัว)
านั งานการวิ ั แห่ ชาติ                             ← เศษ
```

จึง **ซ่อมได้ด้วยการเลือกตัวที่มีเครื่องหมายครบ** ไม่ต้องพึ่ง OCR

## สถาปัตยกรรม

```
popup.html  ─[ปุ่ม นำเข้าจาก PDF]→  import.html (แท็บใหม่ของส่วนขยาย)
                                        │
                    ┌───────────────────┴───────────────────┐
                    │                                       │
              vendor/pdf.js                          pdfText.js (pure)
        อ่าน text item + รูปฝัง                 ประกอบบรรทัด → ซ่อมไทย
                    │                            → ตัดเป็นชิ้น → เดาหมวด
              pdfimage.js                                    │
        กรองพื้นหลัง/มาสก์ + ย่อรูป                          │
                    └───────────────────┬───────────────────┘
                                        ▼
                            หน้าตรวจร่าง (ติ๊ก/แก้/แนบรูป)
                                        ▼
                        Storage.setItems (upsert) + setImages
```

ทำไมเป็นหน้าเต็มไม่ใช่ popup: popup ปิดตัวเองเมื่อคลิกที่อื่น แต่การอ่าน 10 หน้าใช้เวลาหลายวินาที
และหน้าตรวจต้องการพื้นที่ — ทำใน popup แล้วผู้ใช้จะเสียงานกลางคัน

## `pdfText.js` — ตรรกะล้วน มีเทสต์

ไม่มี `chrome.*` ไม่มี DOM ไม่มี pdf.js — รับข้อมูลดิบเข้า คืนโครงสร้างออก เทสต์ด้วย `node --test` ได้ตรง ๆ

```js
buildLines(items)                  // text item ของหน้า → บรรทัด (จัดกลุ่มตามพิกัด y)
repairThai(lines)                  // ทิ้งฝาแฝดพิการ/เศษ เหลือบรรทัดที่สมบูรณ์
segment(pages)                     // บรรทัดทุกหน้า → [{ title, detail, page }]
guessType(text) / guessLevel(text) // คืนค่าที่อยู่ใน Model.TYPES / Model.LEVELS เท่านั้น
toDrafts(pages)                    // รวมทุกขั้น → ร่างพร้อมโชว์
```

**กฎซ่อมไทย** — จัดกลุ่มบรรทัดที่ "เหมือนกันเมื่อถอดเครื่องหมายออก" แล้วเก็บตัวที่นับเครื่องหมาย
(`่ ้ ๊ ๋ ั ็ ์ ิ ี ึ ื ุ ู ำ`) ได้มากที่สุด · บรรทัดที่สั้นกว่าครึ่งของตัวที่ยาวสุดในกลุ่มถือเป็นเศษ ทิ้ง

**กฎตัดชิ้น** — บรรทัดสั้น (< 80 ตัว) ที่ตามด้วยย่อหน้ายาว (> 150 ตัว) คือหัวข้อ · ขอบเขตหน้าปิดชิ้นเสมอ ·
หน้าที่ไม่มีย่อหน้ายาวเลย (หน้าปก/หน้ารูปล้วน) ข้ามและรายงานว่าข้าม

**กฎเดาหมวด** — คำใน `รางวัล เหรียญ ชนะเลิศ เกียรติบัตร` → รางวัล / เกียรติบัตร ·
`โครงงาน วิจัย` → โครงงาน / วิจัย · `ค่าย อบรม bootcamp camp` → การอบรม ·
`จิตอาสา กิจกรรม ชมรม` → กิจกรรม · ไม่เข้าเงื่อนไขไหน → ปล่อยว่างให้ผู้ใช้เลือก

## `pdfimage.js`

รับ `page` ของ pdf.js คืนรูปที่ใช้ได้จริง

- ดึงจาก operator list (`OPS.paintImageXObject`) → `page.objs.get(name)` → canvas → JPEG
- **ทิ้ง** รูปด้านสั้นกว่า 200px (ไอคอน/เส้น) · รูปที่กว้างเกิน 2,400px และครอบทั้งหน้า (พื้นหลัง) ·
  รูปที่เป็นสีเดียวล้วน (มาสก์ของ Canva) · รูปซ้ำ (เทียบด้วย hash ของพิกเซลย่อ 16×16)
- **ย่อ** ให้ ≤ 1800px ด้านยาว และ ≤ 1.2 MB ก่อนเก็บ — เกณฑ์เดียวกับตอนแนบ เพราะ TCASFolio
  ส่งทั้งแฟ้มเป็นก้อนเดียวตอนบันทึก รูปใหญ่ทำให้ได้ 413 (ดู Ruling 22)

## หน้า `import.html`

สี่สถานะ ใช้โทนเดียวกับแผงใหม่ (ขาว/น้ำเงิน TCAS)

1. **เลือกไฟล์** — ลากวางหรือกดเลือก · บอกชัดว่าไฟล์ไม่ออกจากเครื่อง
2. **กำลังอ่าน** — แถบความคืบหน้า "หน้า 4/10" · ยกเลิกได้
3. **ตรวจร่าง** — การ์ดต่อชิ้น: ติ๊กเลือก · หัวข้อ/หมวด/ระดับ/รายละเอียด แก้ได้ในที่ ·
   แถบรูปของหน้านั้นให้คลิกเลือกแนบ · ชิ้นที่เดาหมวดไม่ได้ติดป้ายเตือน ·
   ท้ายหน้าบอกจำนวนหน้าที่ข้ามและเหตุผล
4. **บันทึกแล้ว** — สรุปว่าเพิ่มกี่ชิ้น กี่รูป พร้อมลิงก์กลับ popup

## ต่อกับของเดิม

- อ่าน `Model.TYPES` / `Model.LEVELS` มาใช้เดาและทำ dropdown — ไม่แก้ไฟล์
- บันทึกด้วย `Storage.setItems([...เดิม, ...ใหม่])` แบบ upsert และ `Storage.setImages(id, imgs)` ต่อชิ้น
- id ของร่างสร้างใหม่เสมอ ไม่ชนของเดิม
- เพิ่มปุ่มเดียวใน `popup.html` (`นำเข้าจาก PDF` → `chrome.tabs.create`) ไม่แตะตรรกะอื่น

## ความผิดพลาดที่ต้องจัดการ

| กรณี | พฤติกรรม |
|---|---|
| ไฟล์ไม่ใช่ PDF / เสีย | บอกว่าเปิดไม่ได้ ไม่ crash |
| PDF ใส่รหัส | บอกว่าต้องปลดรหัสก่อน |
| ไม่มี text layer (สแกน) | บอกว่าอ่านตัวอักษรไม่ได้ แนะนำให้ส่งออกใหม่จาก Canva/Word |
| ไฟล์ใหญ่มาก (> 60 หน้า) | เตือนและให้ยืนยันก่อนอ่าน |
| อ่านได้แต่ตัดชิ้นไม่ได้เลย | โชว์ข้อความดิบรายหน้าให้คัดลอกเอง ดีกว่าหน้าว่าง |

## บันทึกจากการลงมือขั้นที่ 1 (`pdfText.js` + เทสต์ · 2026-08-24)

**กฎที่เขียนไว้ในสเปกข้อหนึ่งผิด และเจอเพราะลองกับไฟล์จริง**

สเปกบอกว่า "ย่อหน้ายาว > 150 ตัว คือรายละเอียด" — พอรันจริงได้ **0 ร่างจาก 10 หน้า**
เพราะตัวอ่าน PDF คืน *บรรทัด* ที่ตัดคำไว้แล้ว (~45 ตัว) ไม่มีบรรทัดไหนถึง 150
ต้องเพิ่มขั้น **ประกอบย่อหน้าจากพิกัด** ก่อน (`groupParagraphs`)

ไม้วัดที่ใช้ตัดย่อหน้าคือ **ความสูงตัวอักษร** ไม่ใช่ค่ากลางของระยะห่างบรรทัด —
ลองใช้ค่ากลางแล้วพัง: หน้าที่มีไม่กี่บรรทัดจะมีช่องว่างเดียว ค่ากลางก็คือช่องว่างนั้นเอง
ทุกอย่างจึงถูกรวมเป็นย่อหน้าเดียว หัวข้อติดไปกับเนื้อหา

**โครงสร้างจริงของไฟล์ Canva ละเอียดกว่าที่สเปกเขียนไว้** — ไม่ใช่แค่ "สองชุดคนละบรรทัด"
แต่วางสองชุด **ในบรรทัดเดียวกัน ติดกันตามแนว x** ด้วย เช่น `ทําหน้าที` + `ทำหน้าที่`
กลายเป็น `ทําหน้าทีทำหน้าที่` — บีบเกณฑ์จับบรรทัดไม่ช่วยเลย ต้องลบซ้ำในตัวข้อความ (`dropTwins`)

ตัวชี้ว่าชุดไหนคือตัวจริง: `variantScore` = จำนวนเครื่องหมาย + จำนวน `ำ` − 2 × จำนวน `ํา`
วัดจริงแล้วสองชุดมักได้จำนวนเครื่องหมาย **เท่ากัน** ตัวตัดสินคือ `ำ` กับร่องรอย `ํา`
(ถ้าไม่มีเทอมนี้ ระบบเก็บชุดพิการไว้แทนชุดที่ถูก)

**วัดผลกับเล่ม MU CPE จริง 10 หน้า:** 0 → **13 ร่าง** · ข้าม 2 หน้า (ปก/หน้ารูปล้วน) ·
ข้อความไม่มีคำซ้ำเป๊ะ 8/13 ชิ้น · 34 เทสต์ผ่าน

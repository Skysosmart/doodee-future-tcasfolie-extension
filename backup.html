เว็บอ่านเล่มพอร์ตด้วย OCR แล้วส่ง JSON มาตรง ๆ ไม่ต้องดาวน์โหลดไฟล์เอง ขอแค่ล็อกอินเว็บค้างไว้ — ส่วนขยายจะยิงผ่านแท็บของเว็บให้เอง (ไม่มีแท็บเปิดอยู่ มันเปิดให้เองแล้วปิดคืน)

ปกติไม่ต้องใช้ — มีไว้เผื่อวันหนึ่งเว็บออก API key ให้ ใส่แล้วจะยิงตรง ไม่ผ่านแท็บเว็บ โทเคนเก็บไว้ในเครื่อง และส่งไปที่ doodee-future.com เท่านั้น

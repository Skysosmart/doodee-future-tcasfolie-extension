# Doodee future | tcasfolio extension

ส่วนขยาย Chrome (MV3) สำหรับกรอกแฟ้มสะสมผลงานลง **TCASFolio** (`student.mytcas.com`)
เก็บผลงานไว้ในเครื่องครั้งเดียว แล้วกดปุ่มเดียวให้มันสร้างบล็อก กรอกทุกช่อง และแนบรูปให้

> **English summary** - A local-first Chrome MV3 extension for Thailand's TCAS portfolio
> system. Type each achievement once into a local vault (text + certificate photos), then
> press one button per entry on the TCASFolio page: it creates the right block, fills every
> field, and uploads the photos - resizing oversized ones so the folio still saves. Nothing
> ever leaves the machine; the extension makes no network requests of its own.

## ปัญหาที่มันแก้

TCASFolio ไม่รับ PDF จากเล่มพอร์ตเดิม บังคับให้พิมพ์ใหม่ทีละช่องในตัวแก้ไขของมัน

- 1 ผลงาน = 5 ช่อง (หัวข้อ · หน่วยงาน · ช่วงเวลา · ระดับ · รายละเอียด) + แนบรูปทีละใบผ่าน file dialog
- 11 ผลงาน ≈ 55 ช่อง + 38 รูป - นั่งพิมพ์กับหาไฟล์ในโฟลเดอร์เป็นชั่วโมง
- ยื่นอีกมหาวิทยาลัย = ทำใหม่ทั้งหมด เพราะแฟ้มแยกกันคนละใบ
- เว็บไม่ auto-save · ปิดแท็บผิดจังหวะ = หายหมด

**Doodee future** ทำให้พิมพ์ครั้งเดียวแล้วใช้ได้ทุกแฟ้ม

## ทำอะไรได้บ้าง

| ปุ่ม | ทำอะไร |
|---|---|
| `นำเข้าจากไฟล์ PDF` | อ่านเล่มพอร์ต (PDF) ทั้งเล่ม => เสนอร่างผลงานพร้อมรูปในหน้านั้น => ตรวจ/แก้/ติ๊ก แล้วบันทึกเข้าคลัง |
| `＋ ลงพอร์ต` | กดปุ่ม `＋ เพิ่มรางวัล/โครงงาน/กิจกรรม/การอบรม/ผลงาน` ของเว็บให้ตรงหมวด => รอบล็อกใหม่ => คลิกเลือกให้ => เสนอแผน |
| `เติมทั้งฟอร์ม` | เติมบล็อกที่มีอยู่แล้วและถูกเลือกอยู่ |
| `ชื่อ` `หน่วยงาน` `รายละเอียด` | เติมทีละช่อง (คลิกช่องในเว็บก่อน) |
| `แนบรูป (N)` | ตั้งเลย์เอาต์ให้พอดีจำนวนรูป => **ย่อรูปที่ใหญ่เกิน** => อัปทีละใบจนติดจริง |
| `คัดลอกรายละเอียด` | ก๊อปข้อความไว้ไปวางเอง |
| `?` | การ์ดสรุป 3 ขั้นตอนตรงหน้างาน |

เติม **เฉพาะช่องที่ว่าง** · ไม่แตะเรียงความ · ไม่แตะช่องที่ระบบ verify แล้ว · โชว์แผนก่อนเขียนทุกครั้ง และมีปุ่ม `ย้อนกลับ`

## วิธีใช้

**1 · ใส่ผลงานเข้าคลัง** - เร็วที่สุดคือกด `นำเข้าจากไฟล์ PDF` แล้วเลือกเล่มพอร์ตเดิม
ระบบจะอ่านออกมาเป็นร่างให้ตรวจก่อนบันทึก (ดูหัวข้อ "นำเข้าจากไฟล์ PDF" ด้านล่าง)
หรือกรอกเองทีละชิ้น: กดไอคอนส่วนขยายบน toolbar => กรอกฟอร์ม (หมวด · หัวข้อ · หน่วยงาน · ระดับ · ผลรางวัล · ชั่วโมง · รายละเอียด · แท็ก) => `＋ แนบรูป` ใส่เกียรติบัตร/รูปกิจกรรม => `บันทึกลงคลัง`
มีไฟล์อยู่แล้วใช้ `นำเข้าไฟล์ JSON` ได้

**2 · ลงพอร์ต** - เปิดแฟ้มใน TCASFolio แล้วต่อผลงาน 1 ชิ้น:

```
＋ ลงพอร์ต  =>  ยืนยันเติม  =>  แนบรูป (N)
```

**3 · บันทึก** - ติ๊ก `ค่าใช้จ่าย` เอง แล้วกด `บันทึกแฟ้ม` ของเว็บ
(ส่วนขยาย **ไม่กดบันทึกให้** โดยตั้งใจ - มันคือการส่งข้อมูลเข้าใบสมัครจริง)

รายละเอียดเต็ม: [`docs/วิธีใช้.html`](docs/วิธีใช้.html) (เปิดในเบราว์เซอร์) · [`doodee-future-guide.md`](doodee-future-guide.md)

## นำเข้าจากไฟล์ PDF

เล่มพอร์ตที่ทำจาก Canva/Word ไม่มีโครงสร้างให้อ่านตรง ๆ - ตัวนำเข้าจึงทำสามอย่าง

1. **ซ่อมข้อความไทย** - Canva ฝังข้อความสองชุด ชุดหนึ่งวรรณยุกต์/สระหาย (`ทําหน้าที` คู่กับ
   `ทำหน้าที่`) และวาดทับกันในหน้า ระบบตัดชุดพิการทิ้งด้วยการวัดกล่องที่ซ้อนกัน
   แล้วเก็บชุดที่เครื่องหมายครบกว่า
2. **ตัดเป็นชิ้น** - ประกอบย่อหน้าจากพิกัด (บรรทัดที่ห่างกันไม่เกิน 1.6 เท่าของความสูงตัวอักษร
   คือย่อหน้าเดียวกัน) แล้วใช้บรรทัดสั้นที่ตามด้วยย่อหน้ายาวเป็นหัวข้อ เดาหมวด/ระดับจากคำใบ้
3. **ดึงรูป** - อ่านรูปที่ฝังในหน้า กรองพื้นหลัง/มาสก์/ไอคอน/รูปซ้ำ แล้วย่อให้ <= 1800 px

**ผลกับเล่มจริง 10 หน้า:** 12 ร่าง ข้าม 3 หน้าพร้อมเหตุผล หัวข้อออกมาเป็นชื่อจริง

**ข้อจำกัดที่ต้องรู้:** ตัดชิ้นไม่ถูก 100% (เล่มออกแบบอิสระ) รูปขึ้นเยอะกว่าที่ใช้จริง
เพราะ Canva ซอยภาพเดียวเป็นหลายชิ้น - **ทุกอย่างแก้ได้ในหน้าตรวจ และไม่มีอะไรถูกบันทึก
โดยไม่ได้กด** ไฟล์สแกน (ไม่มีตัวอักษรจริง) อ่านไม่ได้ ระบบจะบอกตรง ๆ ไม่เดามั่ว

ใช้ `pdf.js` (Apache-2.0) ที่ฝังไว้ใน `vendor/pdfjs/` - ไม่โหลดจาก CDN เพราะ CSP ของ MV3
และไฟล์ไม่ออกจากเครื่อง

## ข้อมูลอยู่ในเครื่องล้วน ๆ

- `chrome.storage.local` เท่านั้น - คีย์ `folioItems`, `img:<id>`, `imgIndex`, `panelCollapsed`
- ขอสิทธิ์แค่ `storage` + `unlimitedStorage` · ไม่มี host permission อื่นนอกจาก `student.mytcas.com`
- **ไม่มีการยิงข้อมูลออกนอกเครื่อง** - ตรวจเองได้ด้วย `grep -rnE 'fetch\(|XMLHttpRequest|sendBeacon' *.js`
  เจอที่เดียวคือ `content.js` บรรทัดที่อ่าน `data:` URL ของรูปในคลังมาย่อ (ไม่ได้ต่อออกไปไหน)
- ไฟล์ export ของคลัง (`doodee-future-*.json`) เป็นข้อมูลส่วนตัว - `.gitignore` กันไว้แล้ว ห้าม commit

## ข้อสังเกตของ TCASFolio ที่เจอจากการวัดจริง

โค้ดหลายจุดดูแปลกเพราะต้องรับมือกับพฤติกรรมพวกนี้ — บันทึกไว้กันแก้ผิดทาง

| อาการ | ความจริง | ผลกับโค้ด |
|---|---|---|
| `contenteditable=""` ไม่ใช่ `="true"` | selector ที่เจาะจงค่าจับไม่ได้ | ใช้ `[contenteditable]` + `el.isContentEditable` |
| เขียนหัวข้อแล้วรายละเอียดหาย | เว็บ commit ตอน blur แล้ว **สร้างบล็อกใหม่ทั้งก้อน** พอไปคลิกช่องถัดไป ช่องนั้นหลุดกลางมือ | `blur()` เองหลังเขียนทุกช่อง แล้วรอ ~400 ms ค่อยหาช่องใหม่ในบล็อกเดิม |
| ไฟล์ที่สร้างในส่วนขยายอัปไม่ขึ้น | `File` ที่สร้างใน isolated world ถูก React ของเว็บเมิน | `inject.js` สร้าง `File`/`DataTransfer` ฝั่ง main world ผ่าน `postMessage` |
| กด `บันทึกแฟ้ม` แล้วขึ้น *"เชื่อมต่อเซิร์ฟเวอร์ไม่สำเร็จ"* | เว็บ PUT ทั้งแฟ้มพร้อมรูปเป็นก้อนเดียว รูป 29 MB ใบเดียวทำให้ body 38 MB → เซิร์ฟเวอร์ตอบ **413** ซึ่งหน้า error ไม่มี CORS header เบราว์เซอร์เลยรายงานเป็น network error | ย่อรูปก่อนอัปทุกใบ (≤ 1.2 MB / 1800 px) |
| ปุ่ม `ลบรูป` ลบผิดใบ | มันลบ **ช่องที่เลือกอยู่** ไม่ใช่รูปที่เพิ่งคลิก | ไม่พึ่งการลบอัตโนมัติ - นับรูปจริงในบล็อกแทน |
| จำนวนรูปเพี้ยนหลังแก้ไปมา | ลบ+แนบซ้ำหลายรอบทำให้รูปกองสะสมใน state ที่ไม่แสดงผล | ความจริงเดียวที่เชื่อได้คือหลัง **บันทึกแล้วรีโหลด** |

## สถานะที่ทดสอบจริงแล้ว

ทดสอบกับ `student.mytcas.com` ของจริง (ไม่ใช่หน้าจำลอง) ระหว่างทำแฟ้มมหาวิทยาลัยมหิดล · วิศวกรรมคอมพิวเตอร์ และธรรมศาสตร์ SIIT

- `＋ ลงพอร์ต` => บล็อกเพิ่มถูกหมวด เติมครบ 5 ช่อง
- `แนบรูป` => 5/5 ใบขึ้นจริง · ย่อ 3500×2334 / 1,659 KB => 1800×1200 / 191 KB อัตโนมัติ
- ตัวย่อวัดแยก: 6000×4000 / 29,122 KB => 1800×1200 / 536 KB (−98%, 0.7 วิ)
- แฟ้มมหิดล: 11 ชิ้น · 38 รูป · บันทึกผ่าน (PUT 8.9 MB => 200) · รีโหลดแล้วของอยู่ครบ
- 51/51 เทสต์ผ่าน

**นำเข้าจาก PDF** (ทดสอบกับเล่ม MU CPE 10 หน้า ผ่านหน้า `import.html` จริง)

- อ่านครบ 10 หน้า => 12 ร่าง ข้าม 3 หน้าพร้อมเหตุผล
- หัวข้อออกมาเป็นชื่อจริง (`MakeX: Challenger - Robotics Design & Engineering`,
  `RTARF Cyber Bootcamp 2025`, `Doodee future - Team project`, `OUTSTANDING STUDENT AWARD`)
- เดาหมวดได้ทุกชิ้น รูปในหน้าขึ้นให้คลิกเลือกแนบ

**ยังทำไม่ได้:** ตัดสินใจว่าจะลงผลงานชิ้นไหน · เขียนเรียงความ · ติ๊ก `ค่าใช้จ่าย` (ยังไม่มีฟิลด์นี้ในคลัง) · กดบันทึกแทน
